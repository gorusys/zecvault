# Shared assets

Place **fonts**, **universal icons** (for favicon, Tauri, app stores), and **brand** SVG/PNG here.

- Consumption: copy into `apps/web/public` in your build, or add a Vite `publicDir` alias, or `fs.readFile` from Tauri.
- **Do** keep licenses for third-party fonts in this folder (e.g. `fonts/OFL.txt`).

Empty until you add files; git will track the folder via this README.
